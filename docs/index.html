Try it

Four commands. One terminal.

No key, no setup, no account. Copy a command, paste it into your shell — JSON or a PNG comes back.

Weather Live

Atmosphere, anywhere.

Current weather for any city — temperature, condition, humidity, wind, timestamp.

curl "https://nimbus-api-gxuc.onrender.com/api/v1/weather?city=Berlin"
Parameters
city Required City name — Berlin, Hannover, Tokyo.
Bio · Species Live

Taxonomy as JSON.

Full taxonomy for any species — kingdom through genus, by Latin or common name.

curl "https://nimbus-api-gxuc.onrender.com/api/v1/bio/species?name=Quercus%20robur"
Parameters
name Required Common name (Lion) or scientific (Quercus robur).
Capture Live

The site, on paper.

Screenshot any public URL as a PNG, written straight to disk.

curl "https://nimbus-api-gxuc.onrender.com/api/v1/screenshot?url=https://github.com" -o page.png
Parameters
url Required Fully-qualified URL — must include https://.
Images Live

Search the world's images.

Find high-quality photos by keyword — mountains, coffee, architecture. Paginated, fast.

curl "https://nimbus-api-gxuc.onrender.com/api/v1/images?q=mountains"
Parameters
q Required Search keyword — mountains, cats, coffee.
page Optional Page number. Default 1.
per_page Optional Results per page. Default 10, max 30.
Engineered with Go

A single binary. Quietly running.

One static Go binary. No services to wire. No dashboards to babysit. Boot, listen, respond — exactly like a well-made instrument.

Made the slow way, so it stays fast.

We chose Go because we wanted boring reliability and visible engineering. The whole service is a single compiled binary — small enough to read, fast enough to ignore, dependency-free enough to outlive most subscriptions.

The Nimbus Manifesto · v1.0
Principles

Four ideas we won't quietly trade away.

Public, permanently.

No login, no API key, no quota. If a developer needs it, they should be able to use it on a train at 3am without a credit card.

Transparent by default.

Open source code, open changelog, plain English status page. No surprise breakages. No mystery rate limits. No hidden middleware.

Fast by construction.

One static binary, one process, one job. Latency is a feature; we measure it, publish it, and would rather refactor than apologise for it.

Built to outlast trends.

We think in decades, not quarters. Boring tech. Small surface. Documents written so a future maintainer can pick this up without us.

About the studio

A small studio with a long-term view.

Nimbus is run from a quiet workshop in northern Germany. We're a tiny independent group of engineers who think the open web deserves a few small, reliable APIs that work the way a library works — open, free, and there when you arrive.

We build slowly, in public. We answer email. We document our outages. We'd rather ship one well-considered endpoint than five rough ones.

— The Nimbus team
