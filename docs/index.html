About

We build things that just work.

Nimbus is a small developer studio from Niedersachsen, Germany. APIs, tools, apps — if it's useful and can be open source, we'll build it.

Built with Go

Single binary. Minimal memory. Deploys in seconds. We chose Go because things should be fast and boring.

Forever Free

No paywalls. No "free tier" that expires. Free means free. If it works today, it works tomorrow.

No BS

No signup walls, no dashboard you don't need, no email just to try something. Use it or don't.

Manifesto

We hate closed source.

Every line of code we write is public. Not because we have to — because we believe software should be free to read, study, fork, and improve.

Closed source is a walled garden. You don't own it, you rent it. One API change, one pricing update, one shutdown announcement — and your project breaks. We think that's wrong.

At Nimbus, "open source" isn't a marketing badge. It's the whole point.

Read the Code

Wondering how an endpoint works? Just read it. No black boxes, no decompiled binaries.

Fork & Ship

Don't like our API design? Fork it. Run your own version. We won't send a cease and desist.

Free Forever

No "free trial." No "basic plan." No credit card required. Just free. Always.
